MODEL / METHODOLOGY

Inspect the model.

We solve the best legal starting lineup exactly, respecting duplicate slots and flex eligibility. Weekly totals exclude known bye, unavailable, and started-game players. Missing projections stay missing. Known coverage counts slots that available projected players could fill. The maximum-points lineup may intentionally leave slots empty to bench negative weekly projections; those are not missing data.

Season starter value = max(season projection ÷ 17 − highest projected free agent at that position, regardless of current status ÷ 17, 0), summed across the optimal lineup. This is a full-season weekly equivalent, not a rest-of-season forecast. Bench value is not included. A separate Doubtful/Out/IR-filtered sensitivity excludes DOUBTFUL, OUT/O, and IR/injury-reserve aliases. It retains QUESTIONABLE, SUSPENDED and other statuses outside that explicit set; weekly lineup logic still excludes SUSPENDED. It leaves the primary baseline and scores unchanged. Both calculations use the same exact lineup optimizer. Missing baselines use zero with a disclosed warning. The current ESPN source has no verified ROS field; no ROS number is produced.

Search covers every opposing team, using its six highest season-projected available players eligible for a starting slot and all 1:1, 1:2, 2:1, 2:2 packages. No drops are assumed. We surface only complete-data trades with strictly positive season starter gains for both teams. Ranking = your gain + their gain + 2 × the smaller gain.

AI is disabled by default in deployment config. When the operator enables and configures the provider, run controls start on; uncheck either to opt out. Only request-local anonymous labels and four computed deltas are sent. Names, league/player IDs, rosters, screenshots, OCR and credentials are excluded from model input. AI writes concise plain-text summaries from the deltas. Response structure and direction codes are validated; commentary cannot change computed valuations, verdicts or warnings. Provider failures preserve deterministic results.
